# 7CODE MCP

**الإصدار: 0.4.0** · **النظام: Windows** · **اللغة البرمجية: Python**

أداة لربط مساعد يدعم بروتوكول **MCP** بجهاز ويندوز، بهدف إدارة الملفات، والتحكم في سطح المكتب، وتشغيل أوامر محلية بعد تفعيلها من المستخدم، وتوثيق تقدّم المشاريع في ذاكرة محلية مستمرة.

> **تنبيه:** تعمل الأداة بصلاحيات مستخدم ويندوز الحالي، وليست بيئة معزولة (Sandbox). لا تمنحها صلاحيات أو اتصالًا عن بُعد إلا لجهة موثوقة.

## الوظائف المتاحة

### 1. الملفات والمجلدات

| الوظيفة | أداة MCP | الوصف |
|---|---|---|
| معرفة معلومات الملف | `file_info` | عرض الحجم وتاريخ التعديل ومعلومات التحقق من النسخة. |
| استعراض مجلد | `list_directory` | عرض الملفات والمجلدات ضمن مسار محدد. |
| البحث عن الملفات | `search_files` | البحث حسب الاسم داخل المجلدات الفرعية. |
| البحث داخل الملفات | `search_text` | إيجاد نص داخل ملفات المشروع. |
| قراءة الملفات النصية | `read_text_file` | قراءة النصوص مع دعم الصفحات والترميزات المحددة. |
| قراءة الملفات الثنائية | `read_binary_file` | قراءة البيانات بصيغة Base64 على أجزاء. |
| إنشاء ملف أو استبداله | `write_file` | كتابة ملف مع نسخة احتياطية عند الاستبدال. |
| تعديل جزء من ملف | `edit_text_file` | استبدال نص مطابق بعد التحقق من إصدار الملف. |
| إنشاء مجلد | `create_directory` | إنشاء مجلد ومساراته المطلوبة. |
| نقل أو إعادة تسمية | `move_path` | نقل الملفات أو المجلدات دون الكتابة فوق وجهة موجودة. |
| إرسال إلى سلة المحذوفات | `recycle_path` | نقل الملف إلى سلة محذوفات ويندوز بدل الحذف النهائي المباشر. |

### 2. التحكم في سطح المكتب

| الوظيفة | أداة MCP | الوصف |
|---|---|---|
| عرض الشاشات | `desktop_monitors` | معرفة الشاشات المتصلة وإحداثياتها. |
| عرض النوافذ | `desktop_windows` | استعراض النوافذ المفتوحة. |
| اختيار نافذة | `desktop_focus_window` | تحديد النافذة المسموح بالتفاعل معها. |
| التقاط الشاشة | `desktop_screenshot` | التقاط صورة للشاشة أو جزء منها. |
| النقر | `desktop_click` | نقر زر الفأرة داخل النافذة المحددة. |
| تحريك المؤشر | `desktop_move` | تحريك مؤشر الفأرة. |
| السحب والإفلات | `desktop_drag` | سحب المؤشر بين نقطتين. |
| التمرير | `desktop_scroll` | التمرير رأسيًا أو أفقيًا. |
| ضغط المفاتيح | `desktop_keypress` | إرسال مفتاح أو اختصار لوحة مفاتيح. |
| إدخال النص | `desktop_type_text` | كتابة نص في الحقل المحدد. |

**ضوابط سطح المكتب:** يلزم اختيار النافذة والحصول على لقطة شاشة حديثة قبل كل إجراء إدخال. مُعرّف اللقطة صالح لاستخدام واحد، ولا يغيّر التقاط الشاشة النافذة المستهدفة.

### 3. تنفيذ الأوامر المحلية

| الوظيفة | أداة MCP | الوصف |
|---|---|---|
| تشغيل أمر | `command_start` | تشغيل برنامج محلي مع المعاملات ومجلد العمل المحددين. |
| متابعة التنفيذ | `command_poll` | عرض الحالة والمخرجات ورمز الخروج. |
| إلغاء التنفيذ | `command_cancel` | إيقاف مهمة بدأتها الأداة. |

تنفيذ الأوامر **معطّل افتراضيًا**، ولا يُفعَّل إلا بإذن محلي صريح. لا يمنح صلاحيات مسؤول النظام تلقائيًا، ولا يتجاوز حماية ويندوز.

### 4. ذاكرة المشاريع المحلية (SQLite)

| الوظيفة | أداة MCP | الوصف |
|---|---|---|
| حالة الذاكرة | `memory_status` | معرفة ما إذا كانت الذاكرة مفعّلة وإحصاء سجلاتها. |
| تسجيل مشروع | `memory_project_create` | حفظ اسم المشروع ومساره وهدفه. |
| قائمة المشاريع | `memory_project_list` | استعراض المشاريع المسجلة. |
| استرجاع السياق | `memory_project_context` | عرض هدف المشروع وتقدّمه والخطوة التالية وسجل نشاطه. |
| حفظ نقطة تقدّم | `memory_checkpoint` | توثيق نتيجة مؤكدة أو قرار أو مشكلة والخطوة التالية. |
| البحث في الذاكرة | `memory_search` | العثور على معلومات من نقاط التقدّم السابقة. |

- تُحفظ قاعدة البيانات محليًا داخل `7CODE_MCP/.local/memory.sqlite3`.
- الذاكرة **معطّلة افتراضيًا**. تفعيلها وتعطيلها يتمان من لوحة التحكم على الكمبيوتر، وليس من اتصال MCP.
- عند تفعيلها، يُسجَّل نشاط الأدوات على هيئة **بيانات وصفية محدودة**، وتُحفظ التفاصيل المهمة للمشروع بواسطة `memory_checkpoint`.
- لا يعني ذلك حفظ المحادثات كاملة أو استرجاع كل ما لم يُوثّق. للاستمرار في محادثة جديدة، يجب الاتصال **بنفس خادم MCP** واستدعاء أدوات الذاكرة.
- تعطيل الذاكرة لا يمحو السجلات السابقة. احتفظ بمجلد `.local` عند تحديث الأداة، ولا ترفعه إلى GitHub.

### 5. حالة الخدمة وإيقافها

| الوظيفة | أداة MCP | الوصف |
|---|---|---|
| فحص الحالة | `service_status` | عرض حالة الخدمة والصلاحيات التشغيلية المتاحة. |
| الإيقاف الطارئ | `service_pause` | إيقاف العمليات المحلية؛ ولا تُستأنف إلا بواسطة المستخدم على الكمبيوتر. |

يوجد أيضًا اختصار الطوارئ `Ctrl + Alt + F11` عندما ينجح تسجيله في ويندوز.

## المتطلبات

- جهاز يعمل بنظام **Windows**.
- **Python 3.13 أو أحدث**.
- اتصال بالإنترنت لتنزيل الاعتماديات وعميل Tunnel عند الحاجة.
- إعداد **Tunnel ID** ومفتاح التشغيل من خلال لوحة التحكم المحلية للاتصال عن بُعد.

## التثبيت والتشغيل

1. نزّل المشروع من GitHub بصيغة ZIP وفك الضغط.
2. شغّل الملف `7CODE.cmd` الموجود في جذر المشروع؛ ستفتح لوحة التحكم.
3. اختر **7** لتثبيت الاعتماديات أو إصلاحها.
4. اختر **1** لإعداد معرّف Tunnel ومفتاح الاتصال محليًا.
5. اختر **2** لتشغيل الاتصال، ثم **3** للتحقق منه.
6. إذا أردت ذاكرة المشاريع، اختر **11** لتفعيلها قبل بدء العمل.

**مهم:** حزمتا Tunnel الثنائيتان الموجودتان في ملف ZIP المحلي الأصلي غير مرفوعتين إلى هذا المستودع. يمكن لملف `Setup.ps1` تنزيل عميل Tunnel الرسمي أثناء إعداد المشروع.

## خيارات لوحة التحكم

| الرقم | الوظيفة |
|---|---|
| `1` | إعداد Tunnel ID ومفتاح التشغيل |
| `2` | بدء الاتصال |
| `3` | فحص حالة الاتصال |
| `4` | إيقاف أدوات الملفات وسطح المكتب مؤقتًا |
| `5` | استئناف الأدوات محليًا |
| `6` | إيقاف الاتصال |
| `7` | تثبيت المتطلبات أو إصلاحها |
| `8` | عرض دليل المشروع الموجود داخل الحزمة |
| `9` | تفعيل الاتصال التلقائي بعد تسجيل الدخول إلى ويندوز |
| `10` | تعطيل الاتصال التلقائي |
| `11` | تفعيل الذاكرة المحلية |
| `12` | تعطيل الذاكرة المحلية دون حذف بياناتها |
| `13` | عرض حالة الذاكرة |
| `0` | إغلاق قائمة التحكم دون تغيير حالة الاتصال |

تعرض الواجهة اسم **7CODE** باستخدام ASCII Art.

## الأمان والخصوصية

- لا ترفع ملفات `.local` أو قواعد البيانات أو المفاتيح أو كلمات المرور أو لقطات الشاشة الخاصة إلى مستودعات عامة.
- يتطلب الاتصال البعيد استخدام قناة MCP موثوقة ومصادق عليها.
- توجد قيود على تعديل ملفات الخدمة نفسها من خلال MCP، ونسخ احتياطية عند أنواع محددة من تعديل الملفات.
- سجلات التدقيق لا تحتفظ بنصوص الأوامر أو محتويات الملفات بصورة تلقائية.
- لا تُرسل أسرارًا إلى نقاط حفظ الذاكرة يدويًا، فالملاحظات المدخلة فيها تُحفظ في قاعدة البيانات.

## حقوق المشروع والترخيص

**7CODE** هو اسم هذه النسخة المخصصة وهويتها، وتُنسب الإضافات الأصلية الجديدة إلى 7CODE. تعتمد أجزاء من المشروع على **Windows Local MCP** الأصلي المرخّص بموجب **MIT**؛ تبقى حقوق مساهميه وشروط ترخيصه محفوظة.
