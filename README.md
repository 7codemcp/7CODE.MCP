# 7CODE MCP

**أداة للتحكم في ويندوز عبر MCP** — إصدار **0.4.0**

تساعدك على التعامل مع ملفات الكمبيوتر وبرامجه، وتشغيل الأوامر، وحفظ تقدّم المشاريع محليًا لتكمل العمل في محادثات لاحقة.

## الوظائف

| القسم | ماذا تستطيع الأداة أن تفعل؟ |
|---|---|
| **إدارة الملفات** | قراءة الملفات وإنشاؤها وتعديلها ونقلها، وإنشاء المجلدات وإرسال الملفات إلى سلة المحذوفات. |
| **البحث** | البحث عن ملف باسمه أو عن نص داخل ملفات المشروع. |
| **التحكم بسطح المكتب** | عرض الشاشة والنوافذ، والنقر وتحريك الفأرة والسحب والتمرير والكتابة بلوحة المفاتيح. |
| **تنفيذ الأوامر** | تشغيل البرامج وأوامر البناء والاختبار، ومتابعة نتائجها أو إيقافها. يتطلب تفعيلًا محليًا منفصلًا. |
| **ذاكرة المشاريع** | حفظ أسماء المشاريع وأهدافها، ونقاط التقدم والأخطاء والخطوة التالية في قاعدة بيانات SQLite محلية. |
| **الحماية** | إيقاف العمليات مؤقتًا، والتحكم في الصلاحيات التشغيلية، والاحتفاظ بنسخ احتياطية عند عمليات تعديل محددة. |
| **الاتصال التلقائي** | إمكانية بدء الاتصال عند تسجيل الدخول إلى ويندوز. |

**مهم بشأن الذاكرة:** لا تحفظ جميع المحادثات تلقائيًا؛ تحفظ سجلات نشاط محدودة ونقاط التقدم التي توثّقها الأداة. لاستكمال مشروع من محادثة أخرى، اتصل بنفس الخادم واسترجع ذاكرة المشروع.

## طريقة التثبيت والتشغيل

**المتطلبات:** ويندوز، و**Python 3.13 أو أحدث**، واتصال بالإنترنت أثناء التثبيت.

1. حمّل المشروع من [GitHub](https://github.com/7codemcp/7CODE.MCP/archive/refs/heads/main.zip)، ثم فك الضغط.
2. افتح ملف **`7CODE.cmd`** الموجود في المجلد الرئيسي.
3. من لوحة التحكم، اختر **`7`** لتثبيت المتطلبات وتنزيل عميل Tunnel الرسمي.
4. اختر **`1`** لإدخال **Tunnel ID** ومفتاح الاتصال الخاص بك على الكمبيوتر.
5. اختر **`2`** لبدء الاتصال، ثم **`3`** للتأكد من حالته.

**لتفعيل ذاكرة المشاريع:** اختر **`11`** من لوحة التحكم، ثم استخدم أدوات الذاكرة عبر اتصال MCP.

## أهم خيارات لوحة التحكم

| الخيار | الوظيفة |
|---|---|
| `1` | إعداد الاتصال |
| `2` | بدء الاتصال |
| `3` | فحص الاتصال |
| `4` | إيقاف الأدوات مؤقتًا |
| `5` | استئناف الأدوات |
| `6` | قطع الاتصال |
| `7` | تثبيت المتطلبات أو إصلاحها |
| `9` / `10` | تفعيل/تعطيل الاتصال التلقائي |
| `11` | تفعيل الذاكرة المحلية |
| `12` | تعطيل الذاكرة المحلية دون حذف بياناتها |
| `13` | عرض حالة الذاكرة |
| `0` | إغلاق لوحة التحكم |

يوجد أيضًا اختصار للإيقاف الطارئ **`Ctrl + Alt + F11`** عند نجاح تسجيله في ويندوز.
